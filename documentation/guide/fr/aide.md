# Aide

Cette page centralise les ressources d'aide disponibles et vous indique comment joindre
les bonnes personnes lorsque vous avez une question ou une difficulté.

## Consulter le guide d'utilisation

Le [guide d'utilisation complet](README.md) est organisé par rôle et couvre toutes les
fonctionnalités de l'application. Quelques points de départ utiles :

- [Démarrer avec l'application](01-demarrage.md) — choisir son serveur, activer son
  compte, se connecter, récupérer un mot de passe, naviguer, mode hors connexion.
- [Guide de l'Amapien](amapien/README.md) — planning, inscription aux créneaux,
  contrats, échanges de paniers.
- [Guide du Coordinateur](coordinateur/README.md) — planification des livraisons,
  créneaux de bénévolat, contrats de saison.
- [Glossaire](glossaire.md) — définitions des termes employés dans l'application.

## Besoin d'aide ?

Pour toute question concernant votre compte, vos contrats ou le fonctionnement de
l'application au quotidien, contactez l'**administrateur de votre AMAP**. Il gère
les membres, les inscriptions et peut vous renvoyer une invitation si nécessaire.

Si votre problème touche au serveur lui-même (connexion impossible sur tous les
comptes, problème d'instance), adressez-vous à l'**administrateur de l'instance**
qui héberge votre AMAP. Votre coordinateur peut vous indiquer comment le contacter.

## Questions fréquentes

### Je n'ai pas reçu l'e-mail d'activation ou d'invitation

L'e-mail peut mettre quelques minutes à arriver. Vérifiez votre dossier de courrier
indésirable. Le lien d'activation a une durée limitée (en général 7 jours) — s'il a
expiré, demandez à votre administrateur de vous renvoyer une invitation.

Voir [Activer son compte](01-demarrage.md#activer-son-compte).

### J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez **« Mot de passe oublié ? »** et saisissez votre
e-mail. Un code à 6 chiffres vous sera envoyé ; il vous permet de choisir un nouveau
mot de passe. Le code est valable 1 heure.

Voir [Mot de passe oublié](01-demarrage.md#mot-de-passe-oublié).

### L'application affiche « Serveur injoignable »

Votre appareil n'a pas accès au réseau ou le serveur est temporairement indisponible.
Vos données restent consultables hors connexion et vos actions sont mémorisées
localement — elles seront envoyées automatiquement dès que la connexion sera rétablie.

> **Attention** : se déconnecter efface les modifications en attente d'envoi. Restez
> connecté(e) jusqu'au retour du réseau.

Voir [Travailler hors connexion](01-demarrage.md#travailler-hors-connexion).

### Je ne vois aucun contrat dans « Mes contrats »

Les contrats sont créés et attribués par votre coordinateur. Si l'écran affiche
« Aucun contrat ne vous est actuellement attribué », contactez votre coordinateur.

Voir [Mes contrats](amapien/02-mes-contrats.md).

### Il n'y a pas de bouton pour m'inscrire comme bénévole sur une livraison

Plusieurs situations sont possibles : le créneau est **COMPLET** (toutes les places
sont prises), le créneau a été **annulé** par la coordination, ou aucun créneau de
bénévolat n'a encore été ouvert sur cette livraison. Renseignez-vous auprès de votre
coordinateur si la situation persiste.

Voir [Mes livraisons et l'inscription comme bénévole](amapien/01-mes-livraisons.md).
